4 Settings

Premium itags (256k) need a YouTube cookies file. Free 128k works without cookies.
Proof-of-Origin token — YouTube increasingly blocks the anonymous client on bulk runs; a PO token is the documented fix.
OGG 160k (vorbis-medium) works on free accounts; 320k (vorbis-high) + the AAC tiers need Premium; the FLAC tiers need a .wvd Widevine file (below). ⚠️ Spotify has suspended accounts caught using third-party downloaders — your call.
Export from open.spotify.com with the “Get cookies.txt LOCALLY” extension.
Required for the lossless FLAC tiers above — the same .wvd gamdl accepts (export one from a Widevine L3 device with pywidevine).
Both engines need a wrapper on port 10020, so only one can run at a time — the Wrapper panel stops the other automatically when you switch.
After each download, new ALAC tracks are converted to FLAC (both kept). AAC is skipped automatically.
Each playlist gets a Playlists/{artist}/{title}.m3u listing its tracks in order (no duplication).
Also copies each playlist's tracks into Playlists/{artist}/{title}/ so a playlist is one browsable folder — duplicates files on disk.
Before downloading, links whose tracks already exist locally are skipped (green ✓ owned chips). Re-download by disabling this or toggling Overwrite.
Re-running a Spotify/YouTube album or playlist only downloads the tracks the SQLite ledger doesn't already own (they're queued as individual track URLs). Apple library URLs are delta natively — gamdl skips existing files.
Lets gamdl and votify keep their own SQLite ledgers (data/gamdl.db, data/votify.db) so they never re-download registered media — even after you delete the file. gytmdl has no such flag.
Comma-separated: h264, h265, ask. H.265 = smaller files, needs player support.
Placeholders: {album_artist}, {album}, {year}… See gamdl docs.
Applied to single-disc and multi-disc files. Supports {track}, {title}, {artist}, {album}…
Only applies to multi-disc releases; falls back to the single-disc template above.
Compilation albums land here instead of the artist's own folder.
Native OS notification (Notification Center / Windows toast / notify-send) — fires even when the browser tab is closed.
Same "copy playlist tracks" feature but with zero extra disk (APFS hardlinks; falls back to copy automatically).
Probes new files with ffprobe and warns if ALAC was requested but tracks came back AAC.
Queued downloads wait until this window. Empty = download immediately. May wrap midnight (e.g. 22:00-06:00).
Two-letter country code (US, GB, IN, …). Better matches outside the US catalog.
When set, the batch-finished hook and the 📡 Scan now button call the server's real scan API instead of the generic webhook.
Used when no media server is selected — POSTed when a download batch finishes.
Lets the installed PWA connect from your phone on the same Wi-Fi — open http://<your-ip>:8741. Restart the app to apply.
When set, every API call needs it. Strongly recommended with remote access on. Restart to apply. Saved in your browser.
ntfy.sh, Pushover bridge, Slack/Teams webhook, anything accepting JSON — the Releases panel gets a “Notify me” button that POSTs the list here.
Drop a .txt/.m3u/.url containing Apple Music, Spotify or YouTube links — it downloads automatically and moves to .done/.
Comma-separated substrings — files whose name contains any are skipped by the watch folder.
